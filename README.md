# DuoReveal — Official Website & Public Beta

The 3D Virtual Folding Display for MacBook.

As you tilt your MacBook lid, DuoReveal anchors your real macOS screen into a stationary 90° spatial display in 3D world space. Powered by hardware Apple SPU hinge tracking, ScreenCaptureKit, and Metal at 120 FPS.

### First-Time Launch on macOS Sequoia
If macOS displays *"DuoReveal was blocked to protect your Mac"*:
1. Open **System Settings → Privacy & Security**.
2. Scroll to the Security section and click **Open Anyway**.
3. Or run in Terminal:
   ```bash
   xattr -cr /Applications/DuoReveal.app
   ```
